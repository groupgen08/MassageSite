# 📖 Описание проекта The Fulcrum (Портал здоровья)

Этот репозиторий содержит фронтенд статического сайта "The Fulcrum", разработанного на базе генератора статических сайтов **Eleventy (11ty)** и шаблонизатора **Nunjucks**.

## 🛠 Технологический стек

* **Генератор статических сайтов (SSG):** Eleventy (11ty)
* **Шаблонизатор:** Nunjucks
* **Стили:** Чистый CSS (BEM-подобный подход)
* **Контент:** JSON-файлы (`_data/`)
* **Управление контентом:** Pages CMS (см. ниже)

---

## 🎯 Структура контента и страниц

Все текстовые данные и ссылки на изображения хранятся в формате JSON в директории `_data/`.

| Страница | Файл данных (`_data/`) | Файл шаблона (Nunjucks) | Особенности контента |
| :--- | :--- | :--- | :--- |
| **Видение лидера** | `index.json` | `index.njk` | Гибкий конструктор блоков (`content_blocks`). |
| **Холистический подход** | `holistic.json` | `holistic.njk` | Гибкий конструктор блоков (`page_blocks`) и фиксированный сайдбар автора. |
| **Апитерапия** | `apitherapy.json` | `apitherapy.njk` | Конструктор секций (`page_blocks`) для сложных, специализированных блоков (списки в колонках, галерея). |

---

## ⚙️ Управление контентом через Pages CMS

Конфигурация CMS находится в файле **`.pages.yml`**.

Главная особенность контента — его **динамическая структура** на всех трех страницах, реализованная через массив объектов, называемый **"Конструктор блоков"** (Block Stream).

### Принцип работы

Вместо того чтобы редактировать HTML в текстовых полях, контент-менеджер работает со структурой:

1.  **Выбор типа блока:** (например, "Заголовок H2", "Параграф", "Секция Галерея").
2.  **Заполнение данных:** В зависимости от типа, открываются нужные поля (`text`, `items`, `gallery_items`).

| Типы полей в CMS | Описание |
| :--- | :--- |
| **`type: string` / `text`** | Обычный текст (заголовки, подписи). |
| **`type: image`** | Поле для загрузки изображения с автоматическим сохранением пути в JSON. |
| **`type: object` (list: true)** | Главный "Конструктор блоков", позволяющий добавлять, удалять и менять местами секции контента. |

### Как вносить изменения в контент

1.  Откройте **Pages CMS**.
2.  Выберите нужный файл данных (например, "Холистический подход").
3.  Для изменения основной части страницы перейдите в раздел **"Основной контент (Конструктор)"** (`page_blocks`).
4.  Нажмите "Add New Block" и выберите тип контента, который вы хотите добавить или изменить.

> **⚠️ Внимание:** Поскольку контент динамически собирается в шаблонах Nunjucks, крайне важно **не удалять** и **не переименовывать** главные массивы контента (`page_blocks`, `content_blocks`) в JSON-файлах.

## 🚀 Как запустить проект локально

1.  **Установите зависимости:**
    ```bash
    npm install
    ```
2.  **Запустите сервер разработки (с автоперезагрузкой):**
    ```bash
    npx @11ty/eleventy --serve
    ```
3.  Откройте в браузере адрес, указанный в консоли (обычно `http://localhost:8080/`).
